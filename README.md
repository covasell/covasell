# CovaSell — Prototype frontend V2

Voir `design-system.md` pour la charte graphique complète et l'addendum V2 (section 8).

## Installation
```bash
npm install
npm run dev
```

Deux points d'entrée :
- `/adja-store` — boutique cliente
- `/connexion` — espace commerçant (redirige vers /dashboard)

## Changements par rapport à la V1
Voir design-system.md section 8 (Addendum V2) : navigation restructurée,
nouveaux écrans (connexion, analytics, formulaire produit, suivi commande),
nouveau composant RecommendationCard, PaymentStatusBadge.
